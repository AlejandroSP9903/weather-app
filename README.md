# 🌤️ Weather App

Una aplicación simple para ver el clima de diferentes ciudades.

## Características
- ✅ Busca el clima por ciudad
- ✅ Muestra temperatura en tiempo real
- ✅ Interfaz moderna y responsive
- ✅ Soporta ciudades de Colombia y Argentina

## Tecnologías
- HTML5
- CSS3
- JavaScript vanilla
- Open-Meteo API (clima gratis)

## Cómo usar
1. Escribe el nombre de una ciudad
2. Presiona "Buscar" o Enter
3. ¡Listo! Ve el clima en tiempo real

## Ciudades disponibles
- Bogotá
- Medellín
- Cali
- Cartagena
- Buenos Aires
